# Profile asset sources

All images in this directory are static, self-contained SVGs served from this repository.

- Technology and GitHub logos: official Simple Icons paths, restyled in neutral gray.
- Source: https://github.com/simple-icons/simple-icons
- License: CC0 1.0 Universal — https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md
- The original ten logo source hashes are recorded in ../SOURCES.md.
- Additional source blobs: Figma `6a06daa63a3dbf788f637dfe4bdc1c4a8e169d7e`; Resend `1a625a9d15a43b95b3b7a1947794401da1f6b217`; GitHub `538ec5bf2a9a5724899daf728577cd0b8beaae90`.
- Text labels are outlined locally with DejaVu Sans. No fonts or images are loaded from an external service.
- `identity.svg`: the existing K monogram, arranged in a custom charcoal browser tile.
- The email and source-code symbols are simple original line drawings.

Palette: charcoal #161B22, border #30363D, neutral #C9D1D9, blue accent #7AA9E8.

- `hero-hands.jpg`: edited from the earlier original hand illustration; charcoal/blue palette, with Kaan Hamitler and Frontend Developer typography. Static JPEG, original image dimensions preserved.

## About

I build web interfaces with React and Tailwind CSS, bundled with Vite. I learn by shipping: build the thing, break it, understand why it broke, then rebuild it properly — every project linked on this page is something I actually made. Right now I'm strengthening frontend fundamentals (component structure, state, responsive layout) and learning TypeScript as the next step toward full-stack work. Based in Türkiye; open to junior frontend roles and freelance work.

### Admin Panel UI

A responsive admin dashboard interface — sidebar navigation, overview cards, data tables and form views — built as a frontend-only project.

- **Live:** Not yet deployed <!-- REPLACE with the Vercel URL if/when you deploy it -->
- **Repository:** [Kaan-Developer/ADMIN-PANEL-REPO](https://github.com/Kaan-Developer/ADMIN-PANEL-REPO) <!-- REPLACE ADMIN-PANEL-REPO with the real repo name -->
- **Stack:** React · Tailwind CSS · Vite · JavaScript

**Scope, honestly:** this is the UI layer only. There is no backend, no API calls and no authentication wired up yet — the interface renders with static placeholder data. The next milestone is connecting it to a real API.

**What I built and learned:**

<!-- REPLACE / adjust the three bullets below so they match the actual code in the repo -->
- Split the app into a layout shell (sidebar + top bar) and page-level components, so new admin pages are composed from existing pieces instead of duplicated.
- Made the layout hold up on small screens: the sidebar collapses to an icon rail and wide tables scroll horizontally instead of breaking the page.
- Kept styling consistent by defining a small set of reusable Tailwind component classes (cards, buttons, table rows) rather than repeating one-off utility strings.

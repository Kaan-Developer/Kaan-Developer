## About

<img src="./assets/divider-thin.svg" width="100%" alt="" />

I build web interfaces with React and Tailwind CSS, and I learn by shipping: pick an idea,
build it, break it, understand why it broke, then rebuild it properly. Everything on this
profile is something I actually made, not a template.

Right now I'm focused on getting genuinely good at the frontend fundamentals — component
structure, state, styling systems, responsive layout — while working my way into TypeScript
and backend development.
